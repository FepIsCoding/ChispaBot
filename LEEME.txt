CHISPA CONNECT - proyecto del programa para Mac y Windows
Creado por Fep

La app es independiente: trae la interfaz adentro, no abre ninguna web y anda sin internet.
Tiene permiso para hablar con el robot por USB y mandar avisos.

OPCION A: hacerlo vos en tu Mac (terminal)
1. Instalar Node.js (nodejs.org).
2. En la carpeta del proyecto:
     npm install
     npm run dist:mac
3. Queda en la carpeta dist/: Chispa-Connect.dmg y la app (.app) dentro de dist/mac-universal.
4. Sin firmar: la primera vez, clic derecho sobre la app y Abrir.

OPCION B: que GitHub lo compile (Mac y Windows juntos)
1. En GitHub, crear un repo llamado ChispaBot en la cuenta FepIsCoding.
2. Subir todos los archivos de esta carpeta. Si la carpeta oculta .github no sube
   al arrastrar, crear el archivo a mano: Add file > Create new file, escribir
   .github/workflows/build.yml y pegar el contenido de ese archivo.
3. Pestana Actions > Build > Run workflow. Esperar unos minutos.
4. En Releases quedan Chispa-Connect.dmg y Chispa-Connect-Setup.exe.

La web ya apunta a esos archivos:
  chispabot-fepo1.vercel.app/descargas/chispa-connect-mac
  chispabot-fepo1.vercel.app/descargas/chispa-connect-windows
Funcionan cuando exista la primera release.

Avisos: los instaladores no van firmados. Windows muestra SmartScreen
(Mas informacion > Ejecutar de todas formas).
